# dotfiles

Personal Linux desktop configuration for a Hyprland-based Wayland setup, managed with [GNU Stow](https://www.gnu.org/software/stow/). Each top-level directory is a stow package that maps onto `$HOME`.

## Prerequisites

- Arch Linux (or an Arch-based distro) with `pacman` and an AUR helper such as [`yay`](https://github.com/Jguer/yay).
- Git.

Install `git` and `stow` first if you don't already have them:

```bash
sudo pacman -S --needed git stow
```

## Installing the dependencies

### Core desktop (official repos)

```bash
sudo pacman -S --needed \
  hyprland hypridle hyprlock \
  waybar rofi dunst \
  fastfetch ghostty \
  stow zsh zsh-autosuggestions zsh-syntax-highlighting starship \
  fzf fd eza bat zoxide atuin zellij yazi btop lazygit git-delta \
  direnv xh lazydocker pgcli tailspin \
  brightnessctl playerctl wireplumber pavucontrol networkmanager \
  imagemagick ttf-jetbrains-mono-nerd otf-font-awesome \
  awww hyprshot grim slurp wl-clipboard libnotify \
  cliphist hyprsunset hyprpicker matugen
```

| Package | Used for |
| --- | --- |
| `hyprland` | Wayland compositor (config in `hypr/`, written in Lua) |
| `hypridle` / `hyprlock` | Idle timeout handling and lock screen |
| `waybar` | Status bar |
| `rofi` | App launcher (SUPER+R / SUPER+Space), wallpaper picker, clipboard history |
| `dunst` | Notification daemon |
| `fastfetch` | Terminal system info banner |
| `ghostty` | Terminal emulator |
| `zsh` + `zsh-autosuggestions` + `zsh-syntax-highlighting` | Shell and plugins used in `.zshrc` |
| `starship` | Shell prompt (pill layout, template in `theme/` so it follows the palette) |
| `fzf` + `fd` | Fuzzy finder: Ctrl-R / Ctrl-T / Alt-C, colors from the palette |
| `eza` | `ls` replacement (aliases in `.zshrc`, theme from the palette) |
| `bat` | `cat` replacement and man pager |
| `zoxide` | Smarter `cd` |
| `atuin` | Shell history search on Ctrl-R (themed, `atuin import auto` once to bring in old history) |
| `yazi` | Terminal file manager with image previews (`y`), themed through the palette |
| `zellij` | Terminal multiplexer, `zj` attaches/creates the `main` session |
| `btop` | System monitor, themed through `~/.config/btop/themes/palette.theme` |
| `direnv` | Loads `.envrc` per project directory (needs `direnv allow`) |
| `xh` | `http` / `https` commands for calling APIs |
| `lazydocker` | Docker TUI (`lzd`) |
| `pgcli` | Postgres client used by `pgsh` (falls back to `psql` inside the container) |
| `tailspin` | Highlights logs piped through `tspin` (used by `dlogs`) |
| `lazygit` + `git-delta` | Git TUI and diff pager (`lg`); delta only gets wired into git once it is installed |
| `brightnessctl` | Laptop brightness keybinds |
| `playerctl` | Media key bindings |
| `wireplumber` | Provides `wpctl`, used for volume keybinds |
| `pavucontrol` | Audio mixer (opened from the waybar pulseaudio module) |
| `networkmanager` | Provides `nmcli`, used by the network module |
| `imagemagick` | Provides `magick`, used to generate thumbnails in the wallpaper picker script |
| `ttf-jetbrains-mono-nerd` | Nerd Font used across waybar, rofi, ghostty |
| `otf-font-awesome` | Icon glyphs used by waybar |
| `awww` | Wallpaper daemon (autostarted in `hyprland.lua`, sets/transitions wallpapers) |
| `hyprshot` + `grim` + `slurp` + `wl-clipboard` | Screenshots (Print / SUPER+SHIFT+P), saved to `~/Pictures/Screenshots` and copied to clipboard |
| `libnotify` | Provides `notify-send`, used by hyprshot to post a notification |
| `cliphist` | Clipboard history (SUPER+SHIFT+V) |
| `hyprsunset` | Night light, schedule in `hypr/hyprsunset.conf` |
| `hyprpicker` | Color picker (SUPER+SHIFT+C) |
| `matugen` | Extracts a palette from the wallpaper for `theme-mode wallpaper` |

### AUR packages (install with `yay`)

```bash
yay -S --needed \
  wlogout waypaper brave-bin bibata-cursor-theme-bin
```

| Package | Used for |
| --- | --- |
| `wlogout` | Power menu (SUPER+Escape) |
| `waypaper` | GUI wallpaper picker (alternative to the rofi script) |
| `brave-bin` | Browser autostarted on login |
| `bibata-cursor-theme-bin` | Cursor (Bibata-Modern-Ice) for Hyprland, GTK, Qt and SDDM |

### oh-my-zsh (not a pacman/AUR package)

`.zshrc` expects oh-my-zsh to already be installed, plus the `fzf-tab` plugin (Tab completion menu through fzf):

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
git clone https://github.com/Aloxaf/fzf-tab ~/.oh-my-zsh/custom/plugins/fzf-tab
```

## Applying the dotfiles

Clone the repo and stow the packages you want:

```bash
git clone <this-repo-url> ~/Code/personal/dotfiles
cd ~/Code/personal/dotfiles
stow hypr waybar rofi dunst fastfetch ghostty waypaper wlogout zsh assets theme atuin zellij yazi
```

Login screen (SDDM) theme, outside `$HOME` so it needs root:

```bash
sudo ./sddm/install.sh
```

Boot splash (Plymouth): backs up `/etc/kernel/cmdline`, adds `quiet splash` and the dracut module, then rebuilds the initramfs. `uninstall.sh` reverts all of it.

```bash
sudo pacman -S plymouth
sudo ./plymouth/install.sh
```

`.stowrc` already points the stow target at `$HOME`, so no `-t` flag is needed. Re-run `stow -R <package>` after adding new files to a package (e.g. a new wallpaper) to refresh its symlinks.
